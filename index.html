同一句話，兩個 skillOne prompt, two skills

我們把一模一樣的一句提示分別交給兩個會「畫東西來解釋事情」的 Claude Code skill： 走手繪感等角線稿路線的 anatomy，以及走寫實 three.js 3D 模擬路線的 machine。 兩邊都沒有人工修圖，影片就是它們自己產出的動畫。第一回合考抽象演算法，第二回合考真正的機械， 看看各自在主場與客場的表現。 We gave the exact same one-line prompt to two Claude Code skills that explain things by drawing them: anatomy, which makes crafted isometric line drawings, and machine, which builds photoreal three.js 3D simulations. Nothing was retouched by hand; every video is the animation the skill produced on its own. Round 1 is an abstract algorithm, round 2 is a real machine, so each skill plays one game at home and one away.
